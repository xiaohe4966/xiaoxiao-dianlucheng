# 小小电路城 ⚡

给 5 岁小朋友的网页电路模拟实验室：把电池、电阻、LED、灯泡、喇叭、二极管、电机、面包板拖到工作台上，用小圆点连电线，按「通电试试」就能看到电流在电线里流动。电路短路时，会「砰」地爆炸一下，提醒小朋友：电线不能直接连电池两头。

## 怎么打开

- 方式一（推荐）：在线玩 **<https://xiaohe4966.github.io/xiaoxiao-dianlucheng/>** —— 手机、平板、电脑打开就能玩，不需要安装任何东西。
- 方式二：直接双击 `index.html`，用浏览器打开即可（完全离线）。
- 方式三：在本目录启动一个本地网页服务器：

  ```bash
  python3 -m http.server 8787
  ```

  然后浏览器访问 <http://127.0.0.1:8787/>

## 怎么玩

1. **放零件**：从左边「零件箱」把零件拖到工作台，或者点一下零件，它会自己跳进工作台。
2. **连电线**：点零件上的小圆点，再点另一个小圆点，就连好一根电线。想提示所有接线点，可以点一下「电线」按钮。
3. **通电**：按右上角 **「通电试试」**。电线里会出现流动的小电流，LED、灯泡、电机、喇叭会开始工作。
4. **修改**：拖动零件可以搬家；选中零件后点 🗑️ 删除，或者双击零件删除；点一下**电线**，中间会出现 **✕**，点它就能删掉这根电线；按「撤销」（Ctrl/⌘+Z）都能找回来。
5. **短路**：如果电线把电池的 + 和 − 直接连起来，通电后会 💥 爆炸（模拟效果）。中间放一个灯泡、电阻、电机或喇叭就不会短路了。
6. **认零件**：
   - 电池：电流从 + 出发，回到 −；
   - 电阻：电流的「减速带」，保护 LED；
   - LED：长脚（+）接电池正极，短脚接负极；接反了不亮；
   - 二极管：单向门，只允许电流从三角形尖尖的方向通过；
   - 面包板：红色 + 轨、蓝色 − 轨左右相通，可以把电分给多个零件；
   - 灯泡、电机、喇叭：电流经过时分别会发光、旋转、发声。

## 给家长/老师的话

- 页面里的「爆炸」只是动画效果，现实中短路会让电池发烫、漏液甚至起火，请务必告诉孩子：**真电池不能直接短路**。做真实实验时建议用 1.5V/3V 电池盒 + 保护电阻，并在大人陪同下进行。
- 程序使用「修改节点法」解电路：把每个零件当成电阻 / 电压源 / 二极管，解出节点电压后再算电流，所以串联、并联、多个电池、正反接都能正确显示电流大小和方向。
- 数据全部保存在浏览器本地（localStorage），不上传任何内容。清空后可以用「撤销」找回，也可以加载示例重新开始。
